## Pendiente de completar manualmente en `Informe_Uso_GitHub_Estudiantes.docx`

Los siguientes campos no se pueden completar automáticamente y quedan pendientes:

- **Número de informe**: el correlativo institucional (`INFORME No. ___-2026`) lo asigna la secretaría/docente.
- **Anexo de evidencias**: capturas de pantalla de (1) el aula creada en GitHub Classroom, (2) la asignación de tareas, y (3) evidencia de los estudiantes en alguna asignación — deben insertarse manualmente ya que requieren acceso a la sesión de GitHub Classroom.
